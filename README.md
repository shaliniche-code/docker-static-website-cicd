# Docker Static Website CI/CD

## Project Overview

This project demonstrates a complete DevOps CI/CD pipeline for deploying a static website using Docker, GitHub, Jenkins, and AWS EC2.

---

## Technologies

- Linux (Ubuntu)
- Git
- GitHub
- Docker
- Jenkins
- AWS EC2
- HTML
- CSS
- JavaScript
- Nginx

---

## Architecture

Developer

↓

GitHub Repository

↓

Jenkins Pipeline

↓

Docker Image

↓

Docker Container

↓

Website

---

## Features

- Static responsive website
- Dockerized deployment
- GitHub integration using SSH
- Jenkins CI/CD pipeline
- Automatic deployment
